== BACnet (Building Automation and Control Networks)

== Supported Operations

The Java driver is an *active BACnet/IP client* for unicast ReadProperty /
ReadPropertyMultiple / WriteProperty against the UDP peer in the connection
string. Subscriptions still passively report COV notifications observed on
the socket (they are not SubscribeCOV).

Tag addresses follow the plc4go form:

----
ANALOG_INPUT,1/PRESENT_VALUE
ANALOG_VALUE,10/PRESENT_VALUE{8}
BINARY_INPUT,1/PRESENT_VALUE
DEVICE,12001/OBJECT_LIST
----

`{priority}` is the BACnet write priority (1..16). `[index]` is an optional
array index. Multiple properties on one object may be joined with `&`.
